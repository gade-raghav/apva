# Code of Conduct

APVA follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

To report a violation, contact the maintainers listed in [MAINTAINERS.md](MAINTAINERS.md).
If a report involves a maintainer, or you are not satisfied with the response, you can
contact the CNCF Code of Conduct Committee at <conduct@cncf.io>.
